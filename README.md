# BIOS640-Week-4-Assignment
## Overview of Repository 
This repository uses R to explore the NHANES dataset. The NHANES dataset is a survey, conducted by the United States CDC, assessing the nutritional status of children and adults. This repository focuses on the relationships between Age, Gender, Ethnicity, and Systolic Blood Pressure readings through data manipulations and data visualisations.
